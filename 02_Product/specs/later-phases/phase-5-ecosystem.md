# Phase 5 - Ecosystem

Status: PROPOSED (feature level) · Decisions to be made with the founder before specifying

## Goal
Grow beyond a single app: connect with the founder's other products, sell to organizations, and add tracks.

## Features
| # | Feature | Notes |
|---|---|---|
| 5.1 | Learn with Alphonso connection | Shared login and a funnel from Alphonso's gamified daily learning into Parle roadmaps and tutors. Decision #12 deferred this; design together with the Alphonso session |
| 5.2 | B2B: employers | Employers sponsoring French for staff (e.g. healthcare, construction, customer service); seat-based billing, progress reports |
| 5.3 | B2B: settlement and immigration partners | Settlement agencies and licensed consultants refer clients; referral or seat model; no advice given by Parle |
| 5.4 | New tracks | Quebec immigration, French for healthcare, construction, business, customer service, school/university |
| 5.5 | Group classes | Small-group tutor sessions at lower price per learner |
| 5.6 | Adaptive ecosystem analytics | Outcome data across learners improves roadmap rules and feasibility estimates |
| 5.7 | Other languages | Reuse the engine for English for francophones or other target languages |

## Risks
Brand dilution if tracks multiply too fast; B2B sales cycles; keep the core loop the product's center.
