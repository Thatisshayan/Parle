# Parle - French Learning & Teaching Platform

Workstation for Parle. Each top-level folder has one owner area.

| Folder | What lives here |
|---|---|
| `00_Inbox` | Raw inputs that haven't been processed yet (sketches, ChatGPT chats, notes) |
| `01_Strategy` | Vision, market research, competitors, business model |
| `02_Product` | Specs: `specs/00_master-spec.md` (start here), `specs/phase-1-mvp/`, `specs/later-phases/`; user flows |
| `03_Design` | Wireframes, brand, visual references |
| `04_Content` | Curriculum per learning goal, exam prep, AI content generation rules |
| `05_Operations` | Tutor recruiting/vetting/onboarding, support, legal & compliance |
| `06_Build` | Buildy.ai prompts, session logs, screenshots, export/decoupling plan |
| `07_Engineering` | Source code once exported from Buildy.ai |
| `08_Marketing` | Launch plan, acquisition channels |
| `09_Finance` | Pricing, projections |
| `10_Decisions-Meetings` | Decision log and meeting notes |

**Resuming work? Read [`HANDOFF.md`](HANDOFF.md) first**: current state, next steps, how to drive the browser.
Then `10_Decisions-Meetings/DECISIONS.md` for what's been decided.

**Status (2026-10-10):** Phase 1 is being built on Buildy.ai as a test-only demo. Modules 1-2 done, Module 3
(roadmap engine) in its fix round, Modules 4-8 not started. No application code is in this repo yet; it arrives in
`07_Engineering` at export.
