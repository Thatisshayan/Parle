Decisions
Match levels use the average of current skill estimates, falling back to self-assessment; ties round up, and A0 matches A1 tutors.
Goal-to-specialty matches use a fixed map. Unknown goals receive no goal-fit points.
Availability score uses overlapping minutes across the learner’s saved windows. Time windows are morning 6am–noon, afternoon noon–5pm, and evening 5–10pm. Without saved windows, availability gets 0 points and that filter is disabled.
“Unspecified” budget earns full price-fit points; an explicit “no budget” earns none. Price filters use hourly USD rates.
Demo reviews are labeled and count toward the three-review threshold. Published schedule and reply updates refresh hourly; an admin can refresh the profile sooner.
Security gaps
Learner screens and server actions check the learner role, but the account-access rules cannot distinguish Parle learners from tutors for direct data requests. A signed-in tutor may be able to read already-published tutor profiles, which contain only approved public fields. System record details may also reveal the administrator’s email. These access paths were not tested across accounts.
Demo reviews use generated lesson references, not real completed lessons. The normal reply flow allows one reply, but direct account-level changes could create duplicates; the public profile selects the earliest valid reply.
Availability is displayed as listed windows, not bookable or reserved slots. The 14-day view was not browser-tested across accounts or daylight-saving changes.
