PART A
1. Audit log: an admin_audit_log record (who, action, target type and id, old value, new value, when) written by every admin action that changes a status, a setting or content, starting with the actions below and the existing tutor decisions (approve, needs changes, reject, suspend, verify certificate). 2. Settings screen backed by app_setting (key, value, updated_by, updated_at): Free AI messages per day (default 10), Premium fair-use AI messages per day (300), Premium live-voice minutes per month (60), commission % (20), payout delay hours (72), cancellation window hours (24), minimum lesson charge in USD (8), feature flags "Live voice" (off) and "Premium roadmap triggers" (off). 3. Users screen: search learners and tutors by name or email; open a user to see role, time zone, native language, plan, sign-up date, last activity; for a learner the goal, track, current level per skill, this week's plan summary and AI messages used today; for a tutor the application status, rate and availability summary. Actions: "Give Premium (comp)" / "Remove comp" (sets a plan flag only, no payment), and "Disable account" / "Enable account" (a disabled user is signed out and cannot sign in). Each action asks for a reason and writes the audit log.
4. Admin users: list admins, invite an admin by email, remove an admin (never the last one, never yourself); audit logged.
5. Access: every admin screen and every admin action is checked on the server for the admin role; a learner or tutor opening an admin address is sent away.
