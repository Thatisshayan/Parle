Buildy GuideFrom idea to launchHomeGetting StartedHow Buildy WorksFeaturesDashboardHelp CenterTech SupportDashboard → DeveloperDeveloper is the technical corner of the Dashboard. It is for you (or a developer you work with) when you want to look under the hood of your app. Most people never open this section. Buildy writes and maintains the code for you, so day-to-day building does not require it.Advanced, optional areaOpening Developer and browsing code will not change or break your live site. You can explore safely. When you want changes, ask Buildy in chat so everything stays consistent. What is inside Developer Mode / View CodeBrowse the actual code Buildy wrote for your app: pages, styles, and data definitions. This is read-only exploration so you (or a hired developer) can see how things are structured.Looking at code here does not edit your app. Changes still happen by asking Buildy in chat. Code ExportDownload a copy of your project's code. Useful when you want a backup, need to share files with an outside developer, or want the source offline for review.Exporting gives you a snapshot. Your live Buildy project keeps running as usual. When to use itYou are handing the project to a developer who wants to review the source.You want a backup or offline copy of the code for audits or records.You are curious how the app is put together and want a guided look at the files. When not to worry about it•Normal building in chat: describe what you want and review the preview.•Publishing updates so customers see the latest version.•Marketing, ads, blog posts, contacts, domains, and day-to-day business tools.•Tweaking settings, branding, or sign-in. Those live in other Dashboard sections.How changes stay consistentEditing code outside Buildy is not how you improve the app. If you change files only in a local export, Buildy will not automatically know about those edits, and your live project can drift out of sync. The reliable path is always the same: ask Buildy in chat what you want changed. Buildy updates the project and keeps backups and checkpoints for you.TipDeveloper is marked Advanced because it exposes technical detail most founders never need. Nothing here breaks your live site just by looking. Use it when a developer asks for source access or when you want an export. Otherwise, stay in chat and the rest of the Dashboard.
